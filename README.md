# RIVALS — 1v1 デュエル FPS

ブラウザで動く 1v1 のアリーナ FPS です。AI の「ライバル」と 5 点先取で戦います。
Three.js（`lib/` に同梱）だけで動き、ビルド不要・画像/音声ファイルも不要です（テクスチャと効果音はすべてコードで生成）。

## 遊び方

ES モジュールを使うため、ローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## ルール

| 項目 | 内容 |
| --- | --- |
| 勝利条件 | 5 点先取（1 キル = 1 点） |
| 試合時間 | 1 分 30 秒（時間切れで同点ならサドンデス） |
| 体力 | 150 |

## ロードアウト

| スロット | 武器 | 性能 |
| --- | --- | --- |
| 1 メインウェポン | アサルトライフル | 胴体 12 / ヘッドショット 15、マガジン 20 発 + 予備 100 発、フルオート |
| 2 サブウェポン | ハンドガン | 胴体 12 / ヘッドショット 15、マガジン 13 発 + 予備 75 発、セミオート |
| 3 メレー | 拳 | 30 ダメージ、弾なし。装備中は空中で 1 回ジャンプできる |
| 4 ユーティリティ | グレネード | 最大 75 ダメージ（距離で減衰、自爆は半減）、クールタイム 50 秒 |

弾薬と体力はラウンドごとに回復します。グレネードのクールタイムは試合中ずっと引き継がれます。

## マップ

- **アリーナ** — 夜のネオンスタジアム。左右対称。中央の台座、両サイドのキャットウォーク（スロープで登れる）、低いカバーとブロック。
- **バトルグラウンド** — 昼の砂漠の軍事拠点。積み上げたコンテナ、窓のある廃墟（屋上に登れる）、監視塔 2 基、土嚢、岩。

## 操作

| キー | 動作 |
| --- | --- |
| WASD | 移動 |
| Space | ジャンプ（拳装備中は空中でもう 1 回） |
| Shift | ダッシュ |
| C / 左 Ctrl | しゃがみ（ダッシュ中はスライディング） |
| 左クリック | 攻撃 |
| 右クリック | エイム（ADS） |
| R | リロード |
| 1〜4 / ホイール | 武器切替 |
| Q | 前の武器に戻す |
| G | グレネードを即投げ |
| Esc | ポーズ |

## ライバル（AI）

難易度はイージー / ノーマル / ハード。A* のナビゲーショングリッドで移動し、反応速度・照準のブレ・ヘッドショット率が難易度で変わります。
ストレイフ、距離の調整、弾切れ時のハンドガンへの持ち替え、低体力時の遮蔽物への退避、隠れた相手へのグレネード投擲などを行います。

## 構成

```
index.html        画面と HUD
css/style.css     UI スタイル
js/main.js        メニュー・入力・ポインターロック
js/game.js        試合の進行、射撃・ダメージ、描画ループ
js/player.js      プレイヤー操作（移動、スライディング、二段ジャンプ、ADS、リコイル）
js/bot.js         ライバル AI
js/nav.js         A* ナビゲーション
js/fighter.js     プレイヤー/ボット共通の体力・武器状態
js/weapons.js     武器データと一人称ビューモデル
js/character.js   ボットのキャラクターモデル
js/maps.js        アリーナ / バトルグラウンド
js/world.js       当たり判定（AABB + スロープ）とレイキャスト
js/effects.js     パーティクル・トレーサー・弾痕・爆発
js/textures.js    手続き生成テクスチャ
js/audio.js       WebAudio で合成した効果音
lib/              three.js r170 と後処理アドオン（MIT、lib/THREE_LICENSE）
```
