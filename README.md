# シュワッとタイピング

打つたびに泡がはじける、炭酸系タイピングゲーム。`index.html` 1枚で動きます（ブラウザで開くだけ / GitHub Pages にそのまま置けます）。

## あそびかた
- 難易度（やさしい / ふつう / むずかしい）を選んで Space でスタート
- 60秒勝負。ノーミスで言葉をクリアすると +1秒（最大15秒）
- ノーミスで言葉（文）をクリアするたびにコンボ +1（ミスで 0 に戻る）。1コンボごとに倍率 +0.2、8コンボでフィーバー（得点2倍）
- ノーミスで打つとバブルゲージが溜まり、満タンになると自動でバブルボム。画面中の泡が中心から波のように割れて得点に
- `shi/si`、`chi/ti`、`n/nn`、`kka/xtuka` など、いろいろなローマ字入力に対応
- Esc でタイトルへ戻る
- 右上のボタンで BGM / すべての音をそれぞれオン・オフ

## ランク戦（全50段階）
- ブロンズ → シルバー → ゴールド → プラチナ → エメラルド → サファイア → ルビー → アメジスト → ダイヤモンド → レジェンド（各5段階）
- 60秒で「正しく打った数」がノルマ以上（＋正確率の条件）なら勝ち
- 毎試合 ELO がもらえる（ノルマ達成度ぶん＋勝利ボーナス＋連勝ボーナス）。ELO が 200 たまるごとに次のランクへ
- ランクが上がると、ノルマ（60打 → 450打）、出題（短い単語 → 長い文）、正確率の条件（Lv11〜）、ミスでの時間減少（Lv26〜）が厳しくなる
- 進み具合はブラウザに保存

## 気持ちよさの仕掛け
- 1打ごとにコンボに合わせて音階が上がるポップ音（WebAudio で合成、音声ファイルなし）
- 打った文字から泡と星がはじけるパーティクル
- 単語クリアで紙吹雪・リング・スコアのポップアップ
- コンボの節目でバナーと紙吹雪、フィーバー中は背景が虹色に
- BGM は王道進行のポップなループ（WebAudio で合成）。フィーバー中と残り10秒でテンポや音数が増える
- コンボ表示はカードの下、紙吹雪はカードの後ろに出るので打つ文字をふさがない
- 結果画面はランク（SS〜D）とスコアのカウントアップ、自己ベストは端末に保存
